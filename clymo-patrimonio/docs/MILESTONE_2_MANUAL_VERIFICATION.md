Performed on 9–11 September 2026 against the local production application and real local Supabase/PostgreSQL. Only synthetic identities and financial values were used. These are **local** results; no hosted verification or physical iPhone Safari test has occurred. Milestone 1 evidence remains separately recorded in `MANUAL_VERIFICATION.md` and `MILESTONE_1_VERIFICATION.md`.

## Browser and sessions

The Codex in-app Chromium browser opened `http://127.0.0.1:3100` and an independently authenticated cookie session at `http://localhost:3101`. Both application servers used the same local database. These are independent origin/cookie sessions in one browser; the automated suite additionally uses two separate Playwright browser contexts. Owner/helper credentials were loaded privately from the ignored local identity file and were not recorded in screenshots or this document.

## Independent request and database evidence

`MILESTONE_2_HTTP_VERIFICATION.json` records **53 passed, 0 failed** independent HTTP/PostgREST assertions. It covers anonymous redirects and API denial, no financial login HTML, no-store, owner exports and exact totals, helper mutation/export/reset/member/delete denial, cross-household denial, real helper INSERT/UPDATE rejection, invisible B rows, and security headers. These are scripted request checks, not manual browser clicks and not additional unit-test counts.

`MILESTONE_2_DELETION_VERIFICATION.json` records the manually deleted disposable household UUID and zero rows across all 26 household-related tables. The corresponding old API URL was denied.

## Responsive and accessibility evidence
