# Local delivery only

No private staging project is configured for this independent app. The root `.openai/hosting.json` contains only null storage bindings and no existing site/project identity. It belongs to the preserved starter. No deployment, cloud resource, paid service, credential or public financial application was created for this milestone.

The deliverable is the independently installable source plus local screenshots and production-build verification. Run `npm ci`, `npm run build`, then `npm run start` inside `clymo-patrimonio`. Open `http://127.0.0.1:3100`. Both dev and production scripts bind only to loopback. Do not change that binding or publish this app as a real financial service.

A future private staging release must use a separately approved, free or explicitly budgeted environment with access control. `noindex` and loopback development are not user authentication. The exact tested commit/build must be promoted; access, storage boundaries, rollback and the private URL must be verified before inviting anyone.

The GitHub repository stores source code, tests and synthetic screenshots. It is not a deployed financial application. The milestone stays on `codex/clymo-patrimonio-milestone-1`; no merge into `main` is part of delivery.
