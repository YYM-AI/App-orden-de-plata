# Deployment

M1's historical delivery was local only. M2 requires real authentication, PostgreSQL and genuinely private HTTPS staging. Current provisioning and verification status is recorded in [PRIVATE_STAGING.md](PRIVATE_STAGING.md) and [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md).

For local development and production run commands use [LOCAL_SUPABASE_SETUP.md](LOCAL_SUPABASE_SETUP.md). Do not deploy the old open browser prototype as M2 staging. No paid resource or public financial deployment is authorized.
